# Phase 0 Co-Design

## Purpose

Discover the product through real use before building the full platform.

The founding user and family should test workflows manually or in a controlled prototype to understand what is genuinely useful.

## Suggested 14-day study

### Daily morning interaction
Learn what users naturally ask, what they want remembered and what tone feels appropriate.

### Routine support
Identify reminders that help versus reminders that feel intrusive.

### Memory scaffolding
Test Recall → Hint → Guide → Answer and record when it feels empowering or frustrating.

### Health-information conversations
Test explanation quality and where the system must defer to clinicians.

### Family observation
Can a meaningful observation be captured in under 30 seconds?

### Clinician-style review
Would a retired GP consider the summary useful, concise and appropriately cautious?

### Retrospective
Ask what to keep, remove, change, automate and never automate.

## Outputs

- top user intents;
- approved language patterns;
- personal baseline schema hypothesis;
- observation schema hypothesis;
- safety “never do” list;
- clinician-summary prototype;
- MVP keep/change/remove decisions.

## Privacy note

Do not commit Phase 0 personal health data, transcripts or identifying observations to this public repository.
