## Working principle

Create fewer, better assets.

The aim is not to fill every section with imagery. The aim is to build a coherent Vascurra visual world in which every significant image has a clear conceptual job.

## Release rule

Artwork work does not constitute launch approval. The V2 site remains subject to the existing holding-page, preview and noindex rules until explicit founder approval.
