# Motion Guidelines

## Motion character

**Calm · intelligent · organic · connected · soft-futuristic**

Motion should feel biological rather than mechanical.

## Signature logo reveal

Suggested 4–6 second sequence:

1. **Gather** — subtle particles emerge.
2. **Connect** — luminous filaments link.
3. **Grow** — vascular branches extend.
4. **Form** — ribbons weave into the brain structure.
5. **Ignite** — nodes illuminate gently.
6. **Reveal** — wordmark appears and motion settles.

## Ambient loop

- extremely subtle ribbon drift;
- gentle node glow;
- slow breathing rhythm;
- no distracting perpetual spinning;
- seamless 6–12 second loop.

## Accessibility

Respect `prefers-reduced-motion`.

Reduced mode should show the finished logo/hero immediately with no essential information lost.

## Avoid

- flashing;
- strobing;
- abrupt zooms;
- high-speed particles;
- aggressive sound;
- movement that competes with reading.

## Web performance

Prefer lightweight implementations. Evaluate Lottie/Rive/video against performance and accessibility requirements before choosing.
