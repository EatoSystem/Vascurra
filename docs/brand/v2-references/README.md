## Locked luminous palette

The original holding-page gradient is the source of truth. Do not darken or reinterpret these brand stops during implementation:

- deep teal: `#087486`
- cyan: `#13b8c6`
- green: `#50c98a`
- hero cyan: `#0aa3bc`
- hero aqua: `#2ecfc4`
- hero green: `#49c768`

Accessibility adaptations must preserve the visual identity rather than globally replacing these canonical brand colours with darker substitutes.
