# Phase 1 Implementation Plan

> **Current phase name:** Public Platform Phase P1. This plan does not authorize Product Platform Phase 1 or health-data functionality.

## Stage 0 — Repository foundation

- add documentation;
- add `AGENTS.md`, `CLAUDE.md`, Cursor rules;
- create base Next.js app if not present;
- configure lint, TypeScript and formatting;
- establish Vercel preview workflow.

## Stage 1 — Brand foundation

- design tokens;
- typography;
- logo assets;
- responsive container system;
- cards;
- buttons;
- gradients;
- icon treatment;
- background vascular-wave primitives.

## Stage 2 — Global shell

- header/navigation;
- footer;
- metadata;
- SEO foundations;
- mobile nav;
- accessibility basics;
- analytics adapter.

## Stage 3 — Homepage

Build sections in order:

1. hero + static fallback;
2. problem;
3. four experiences;
4. founding principles;
5. trust/safety;
6. science/evidence;
7. CTA.

## Stage 4 — Product pages

- Personal;
- Family;
- Clinical;
- Research.

Use conceptual mockups, clearly labelled where necessary.

## Stage 5 — Trust pages

- Science;
- Privacy;
- About;
- early-access form.

## Stage 6 — Motion

Implement hero animation only after static content and performance are strong.

Requirements:

- reduced-motion mode;
- mobile performance;
- no delayed LCP caused by animation.

## Stage 7 — QA

- responsive screenshots;
- keyboard testing;
- Lighthouse;
- claims review;
- broken-link check;
- form validation;
- production build.
