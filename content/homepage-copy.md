# Vascurra homepage copy

This file is the markdown companion to `content/home.ts`.
Live strings are still rendered from `content/home.ts` so the claims tests in `content/home.test.ts` remain the guardrail.

The HD production-pack mockups contain claims that **must not** be copied onto the site:

- invented scores such as `82/100`;
- invented research statistics (`1,250` participants, `3.2M` data points, percentages);
- named fictional patients or clinicians presented as real;
- “AI-powered insights”, clinical validation, or outcome language that is not in `home.ts`;
- the Section 06 dashboard board as a live image, because it shows prohibited scores and risk-style charts.

Section 06 on the live page therefore uses the earlier conceptual ecosystem art, not `06-one-platform-multiple-perspectives.png`.
