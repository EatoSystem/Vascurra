## Important usage rules
- The reference images are **design references**, not live product screenshots or validated medical functionality.
- Build the actual section in HTML/CSS/React using the existing Vascurra component system.
- Use the device references to reproduce composition, hierarchy, spacing, visual quality and product-family coherence.
- Do not copy illustrative scores, counts, risk ratings, research findings or compliance claims literally.
- Keep the background pure white.
- Do not use the Vascurra brain icon in this section.
- Do not reduce the section to four small equal cards or four identical phones.
- Desktop should feel like one connected product ecosystem.
- Mobile should use a deliberate vertical composition rather than a shrunken desktop layout.
