# Vascurra Brand Assets

These files are approved web derivatives of the existing Vascurra identity and are the source assets for the Phase 1A holding page.

## Files

- `vascurra-brain.webp` — approved Vascurra brain mark for header, hero/static fallback and Coming Soon sections.
- `vascurra-lockup.webp` — approved icon + Vascurra wordmark lockup reference.
- `vascurra-og.jpg` — social/Open Graph preview artwork.
- `apple-touch-icon.png` — touch/app icon derivative.
- `favicon.ico` — browser favicon.

## Non-negotiable usage rule

Do **not** redraw, reinterpret, approximate, replace, recolour randomly, distort or crop the Vascurra brain mark. If a new size or file format is required, derive it from the approved source asset rather than creating a new logo.

The brain mark may be animated through particles, branching, light, subtle scale, glow and masking, but the settled/final frame must resolve to the approved mark.

## Accessibility and performance

- Provide meaningful alt text where the mark carries brand meaning; use an empty alt attribute when it is purely decorative and the brand name is already adjacent.
- Respect `prefers-reduced-motion`.
- Do not make the icon the LCP bottleneck.
- Keep high-contrast body copy separate from decorative imagery.

## Phase 1A public-content boundary

These assets are branding only. They must not be used to imply diagnosis, prediction, risk scoring, medical-device status or clinical validation.
